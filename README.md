# Building an AI Coding Agent

Building an AI coding agent from scratch in Python, one phase at a time.
Each phase adds one new skill to the agent. Each phase is in its own folder and runs on its own.

| Phase | Folder | What we add |
|-------|--------|-------------|
| 1 | [phase-1-foundation](phase-1-foundation/) | A terminal chat program that talks to a local AI model (Ollama) with live streaming answers |
| 2 | _coming soon_ | Agent loop: the agent can use a tool (run terminal commands) |
| 3 | _coming soon_ | File tools: the agent can read, write and search files |

Start with [Phase 1](phase-1-foundation/README.md).
